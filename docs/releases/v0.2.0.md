## Turbo GreenVita 0.2.0

The first GitHub Actions release from the Turbo GreenVita fork. It brings the 0.1.8→0.2.0 rebrand and the streaming stability work completed after the fork.

## Featured changes

### Turbo GreenVita rebrand

- Full rebrand from GreenVita to Turbo GreenVita (`TURBOVITA` title ID): logo, LiveArea, localized strings, release workflow, and package name.
- Reworked game-profile menu and Select button mapping.

### Decoder latency and stability

- Low-delay H.264 decode mode to reduce internal B-frame reordering.
- The low-delay function is imported from `SceVideodecLowDelayUser` by a custom `build.rs`-assembled stub; the original SDK import resolves to a null pointer and crashes immediately.
- Four decoder reference frames to reduce visible corruption during motion.
- Triple-buffered staging and decode-driven render wake-up.
- More tolerant decoder admission control, reducing frame-drop and keyframe-request storms after a single slow decode.
- SDP ICE credential normalization for xCloud session-negotiation edge cases.

### Max bitrate

- Settings now offers a 2, 3, 4, 5, 6, 8, or 10 Mbps cap for xCloud’s client-capabilities message and SDP.
- Settings saved with older 15–50 Mbps options load as 10 Mbps.

### Accuracy note

PHYCONT-NC and full-resolution YUV/GPU conversion were implemented in the next development cycle and are **not** included in this release. Those changes ship in v0.3.0.

## Install

Download and install `turbo-green-vita.vpk` with VitaShell, enable **Unsafe Homebrew** in HENkaku Settings, then complete the Xbox device-code sign-in.

## Test focus

Start a stream and verify the first-frame latency and stability. In Settings → Stream debug info, dropped-frame, queue-full and reset counters should remain lower than the upstream 0.1.8 build during the same scene and bitrate.
