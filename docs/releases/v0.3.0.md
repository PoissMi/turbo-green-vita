- Low-delay H.264 decode mode, with a correct `SceVideodecLowDelayUser` import stub assembled by `build.rs`. The original SDK stub resolves to NULL and causes an immediate prefetch-abort crash.
- Four decoder reference frames.
- Triple-buffered staging, decode-driven render wake-up, and more tolerant decoder admission control.
- SDP ICE credential normalization.
- Max-bitrate Settings: 2, 3, 4, 5, 6, 8, or 10 Mbps. Older higher values saved with previous versions load as 10 Mbps.
- The README now distinguishes the v0.1.8 latency work from the later throughput work.

## Install

1. Download `turbo-green-vita.vpk`.
2. Transfer it to the Vita and install it with VitaShell.
3. Enable **Unsafe Homebrew** in HENkaku Settings so Turbo GreenVita can access the hardware video-decoder module.
4. Launch Turbo GreenVita and complete the Xbox device-code sign-in.

## Test focus

Verify stream startup, colors, aspect ratio and crop, pause/resume, disconnect/reconnect, and repeated stream starts. In Settings → Stream debug info, confirm `mem:PHYCONT-NC` and `out:NV12`.
